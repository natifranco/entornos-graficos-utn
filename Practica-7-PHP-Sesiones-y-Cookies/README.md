
# Práctica 7 — Manejo de Sesiones y Cookies con PHP

Resolución de ejercicios sobre el manejo de sesiones, cookies y bases de datos utilizando PHP.

## Ejercicios

- **Ejercicio 1:** Configuración de estilos CSS mediante cookies.
- **Ejercicio 2:** Contador de visitas utilizando cookies.
- **Ejercicio 3:** Recordar el último nombre de usuario mediante cookies.
- **Ejercicio 4:** Selección de titulares de un periódico mediante cookies.
- **Ejercicio 5:** Manejo de variables de sesión.
- **Ejercicio 6:** Validación de alumnos mediante sesiones y base de datos.
- **Ejercicio 7:** Carrito de compras utilizando base de datos.
- **Ejercicio 8:** Buscador de canciones.

## Tecnologías

PHP · HTML · CSS · MySQL
