## Parte 2: Conceptos de Desarrollo Web

### 1. ¿Qué es una interfaz y cuáles son sus elementos fundamentales?

Una interfaz es el medio mediante el cual el usuario se comunica e interactúa con un sistema o sitio web. Permite acceder a la información y utilizar las funcionalidades disponibles.

Sus elementos fundamentales son:

- **Identificación:** permite reconocer el sitio, su organización o institución mediante logotipos, nombres y otros elementos.
- **Navegación:** permite desplazarse entre las diferentes secciones y páginas.
- **Contenidos:** presentan la información que el usuario busca.
- **Acción:** permite realizar operaciones e interactuar con el sitio mediante botones, formularios, enlaces y controles.

Una buena interfaz debe ser clara, consistente, comprensible y fácil de utilizar.

### 2. ¿Qué es un sistema de navegación y cuáles deben ser sus elementos indispensables?

Un sistema de navegación es el conjunto de elementos que permite al usuario desplazarse por las diferentes páginas y secciones de un sitio web, conocer su ubicación y acceder a la información que necesita.

Sus elementos indispensables son:

- Menú principal.
- Menús secundarios, cuando sean necesarios.
- Enlace a la página de inicio.
- Identificación del sitio.
- Enlaces entre las diferentes páginas.
- Indicadores de ubicación, como las migas de pan.
- Buscador, para facilitar la localización de información.

Debe ser consistente, visible, comprensible y facilitar la orientación del usuario.

### 3. ¿Qué es Flash y qué problemas puede acarrear su uso?

Flash fue una tecnología desarrollada por Adobe que permitía crear animaciones, elementos multimedia, juegos y contenidos interactivos para sitios web.

Se utilizaba principalmente para incorporar animaciones, videos y aplicaciones interactivas.

Sin embargo, su utilización presentaba varios problemas:

- Requería instalar un complemento (plugin) para funcionar.
- No era compatible con todos los dispositivos y navegadores.
- Podía generar problemas de seguridad.
- Consumía muchos recursos del equipo.
- Podía afectar la velocidad de carga del sitio.
- Presentaba dificultades de accesibilidad.
- No funcionaba adecuadamente en muchos dispositivos móviles.

Flash dejó de recibir soporte oficial y fue discontinuado a fines de 2020. Actualmente se utilizan tecnologías como HTML5, CSS y JavaScript para desarrollar contenidos multimedia e interactivos.

### 4. ¿Qué es AJAX y qué problemas puede acarrear su uso?

AJAX (Asynchronous JavaScript and XML) es un conjunto de técnicas de desarrollo web que permite intercambiar información con un servidor de manera asincrónica, utilizando JavaScript, sin necesidad de recargar completamente la página.

Esto permite actualizar partes de una página mientras el usuario continúa interactuando con ella.

Por ejemplo, cuando un usuario realiza una búsqueda y los resultados aparecen automáticamente sin recargar todo el sitio, puede estar utilizándose AJAX.

**Ventajas:**
- Mejora la interactividad.
- Reduce las recargas completas de las páginas.
- Permite actualizar información dinámicamente.
- Puede mejorar la experiencia del usuario.

**Problemas que puede ocasionar:**
- Puede generar dificultades de accesibilidad si no se implementa correctamente.
- Los cambios dinámicos pueden no ser interpretados adecuadamente por algunos lectores de pantalla.
- Puede presentar problemas con el historial y los botones de avanzar y retroceder del navegador.
- Si JavaScript está deshabilitado, ciertas funcionalidades pueden dejar de funcionar.
- Puede complicar la indexación de contenidos por parte de algunos buscadores si no se implementa correctamente.
- Requiere controlar los errores de comunicación con el servidor y los tiempos de respuesta.

Por lo tanto, AJAX debe utilizarse correctamente y contemplar mecanismos alternativos para garantizar que el sitio siga siendo accesible y funcional.
